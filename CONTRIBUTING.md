# Contributing to Literature Clock

Thanks for helping improve Literature Clock. Contributions can add literary passages, improve translations, fix a bug, or make the app and native screensavers better.

## Ways to contribute

- **Suggest a quote** with the [quote issue form](https://github.com/cdmoro/literature-clock/issues/new?template=add-quote.yml). Include its source and enough context to verify the time.
- **Report a problem or propose an improvement** in [GitHub Issues](https://github.com/cdmoro/literature-clock/issues).
- **Translate or review a language** using the [Language Incubator Guide](docs/LANGUAGE_INCUBATOR.md). The technical workflows are in [scripts/TRANSLATING.md](scripts/TRANSLATING.md).
- **Change code or documentation** by opening a pull request against `main`.

## Pull requests

Keep each pull request focused and explain the user-visible change. Include the relevant checks in the description and add screenshots for visual changes when useful. For quote or translation changes, preserve quote IDs and attribution and follow the catalogue-specific guidance in the translation documents.

Before opening a code pull request, run the checks relevant to your change. The [Development Guide](docs/DEVELOPMENT.md) covers setup and common commands. Native screensaver build and installation instructions are in the [macOS](screensavers/macos-native/README.md) and [Windows](screensavers/windows-native/README.md) guides.
