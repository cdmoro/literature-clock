Literature Clock for macOS

Install for the current user:

1. Extract the downloaded ZIP.
2. In Finder, choose Go > Go to Folder and enter ~/Library/Screen Savers.
   Create the Screen Savers folder if it does not exist.
3. Drag Literature Clock.saver into that folder. Replace the existing copy when
   updating.
4. Quit and reopen settings, then select Literature Clock in System Settings >
   Wallpaper > Screen Saver (macOS 13+) or System Preferences > Desktop &
   Screen Saver (macOS 12).

Remove the screen saver by deleting ~/Library/Screen Savers/Literature Clock.saver.
This does not remove your saved screen saver preferences.

These builds are signed locally but are not notarized with an Apple Developer
ID. If macOS blocks the screen saver, open Apple menu > System Settings >
Privacy & Security, scroll to Security, and click Open Anyway for Literature
Clock.saver. Only approve a copy downloaded from the project's official
releases. This approval does not disable Gatekeeper.
